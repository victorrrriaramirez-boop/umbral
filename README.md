# UMBRAL — Cruza la noche

Web de una discoteca ficticia con estética industrial negra, roja y plata. Portada cinematográfica con ambiente animado y cinta continua; relato tipográfico ligado al scroll; selector funcional de sesiones; recorrido de dos salas; menú de pantalla completa; información desplegable y modal de acceso.

## Subir a GitHub
1. Descomprime el ZIP.
2. Crea un repositorio nuevo en GitHub.
3. Sube index.html, style.css, motion.js, README.md y la carpeta assets a la raíz. Mantén la imagen assets/club.png en esa carpeta.

## Publicar en Vercel
1. Importa el repositorio de GitHub en Vercel.
2. Selecciona el preset Other.
3. Deja vacíos los comandos de instalación y compilación; usa la raíz como directorio de salida.
4. Publica el proyecto.

## Vista local
Ejecuta `python3 -m http.server 8000` desde esta carpeta y abre http://localhost:8000.

## Personalización
Modifica las sesiones en motion.js y los textos en index.html. Cambia los colores en style.css. Conecta el acceso con una ticketera al convertirlo en un proyecto comercial.

## Demo y accesibilidad
Club, sesiones y horarios ficticios. No hay ventas ni reservas reales. La imagen de ambiente está generada con IA e incluida localmente; el sitio no necesita servicios externos para cargarla. Controles de teclado, diseño móvil, diálogo nativo y movimiento reducido. El botón de ambiente detiene las animaciones continuas de portada. Sin flechas ni asteriscos decorativos.
